# 更新日志

## 0.1.0

首个 Marketplace 版本。

### 功能

- Android 11+ 无线调试二维码配对与配对码配对；
- IPv4 / IPv6 分段地址输入，自动带入已发现地址，支持粘贴完整地址；
- 设备连接、断开、解除配对、复制 ADB 标识与地址；
- 自动重连上次设备，失败时打开连接页面；
- ADB 状态、mDNS、配对记录与设备资料展示，设备资料本地缓存；
- 连接成功后显示 VS Code 通知；
- 侧边栏控制台：ADB / 设备 / 配对与 IP 连接；宽屏自动切换左右双栏；
- 命令与设置说明支持中文 / 英文自动切换。

### 配置

- `adbWifi.adbPath`：自定义 adb 路径，支持文件选择；
- `adbWifi.serverPort`：默认 5038，避开常见 5037 端口冲突；
- `adbWifi.refreshInterval`：状态刷新间隔。

### 验证

- TypeScript 编译通过；
- 解析 / 配对 / protobuf 单元测试通过；
- VSIX 打包与本地安装验证通过。
