# 移植说明：桌面工具 → VS Code 扩展

本文记录把仓库中的 `ADB-connect-tool`（C# / WPF，v1.3.7.0）移植为 VS Code 扩展时的功能映射、ADB 命令、有意差异与待验证事项。行为依据来自原项目源码（`src/Adb.cs`、`src/Program.cs`、`src/DeviceCatalog.cs`、`src/EndpointInput.cs` 等）与当时的 `docs/使用说明.md`、`docs/开发说明.md`，并整理在本项目 `docs/` 内。

## 1. 形态映射

| 原桌面工具 | VS Code 扩展 | 说明 |
| --- | --- | --- |
| WPF 主窗口（设备表 + 配对区 + 连接区 + 底栏） | Webview 主面板（命令「ADB WIFI: 打开无线调试面板」） | 布局沿用左右分栏：左侧设备列表，右侧配对新设备 + 连接已配对设备，底部状态栏 |
| 行内操作按钮（连接 / 断开 / 解除配对 / 复制标识） | 主面板设备卡片 + 侧边栏富 Webview 卡片；「配对与连接」单独成视图（含用 IP 连接按钮） | Webview 可用完整文字按钮，不受树视图单行限制 |
| 应用内确认对话框 | `vscode.window.showWarningMessage({ modal: true })` | 默认按钮为「取消」语义；Esc 关闭不执行 |
| 诊断窗口（只读 TextBox） | `adbWifi.diagnose` 打开只读文本文档，并写入「ADB WIFI」输出面板 | 文本结构基本保留 |
| 底栏 ADB 路径 / 版本 / mDNS 状态 | Webview 页脚 + 状态栏摘要 + 输出面板 | 状态栏显示已连接 / 已配对数量与错误提示 |
| 窗口图标 / 自定义标题栏 / 圆角 | 活动栏 SVG 图标 | 原 WPF 专属外观不移植 |
| 自定义暗色主题 | VS Code 主题变量（`--vscode-*`） | 自动适配亮 / 暗主题 |

## 2. ADB 命令与子进程（沿用原工具约束）

所有命令都按 `adbWifi.serverPort` 注入 `-P`（默认 5038）；子进程环境统一删除 `ADB_SERVER_SOCKET`、`ANDROID_ADB_SERVER_ADDRESS`、`ANDROID_ADB_SERVER_PORT`，设置 `ADB_USB=0`、`ADB_EMU=0`；配对时额外删除 `ADB_TRACE`，并把配对码经 stdin 以 ASCII 传入。仅影响子进程，不修改系统环境变量。

| 用途 | 命令 | 超时 |
| --- | --- | --- |
| 版本 | `adb -P 5038 version` | 4000 ms |
| 设备列表 | `adb -P 5038 devices -l` | 6000 ms |
| mDNS 服务表 | `adb -P 5038 mdns services` | 3000 ms |
| mDNS 后端探测 | `adb -P 5038 mdns check` | 2500 / 3500 ms |
| mDNS 流式监听 | `adb -P 5038 mdns track-services --proto-text` | 长驻 |
| 已知主机回退 | `adb -P 5038 mdns list-known-hosts --proto-text` | 3000 ms |
| 硬件序列号 / 品牌型号 | `adb -P <port> -t <transport_id> shell getprop ro.serialno / ro.product.brand / ro.product.model / ro.product.manufacturer` 或 `-s <serial>` | 2500 ms |
| 配对 | `adb -P 5038 pair <endpoint>`（配对码走 stdin） | 20000 ms |
| 连接 | `adb -P 5038 connect <endpoint>` | 12000 ms（本次运行缓存地址 4000 ms） |
| 断开 | `adb -P 5038 disconnect <serial>` | 6000 ms |
| 服务状态 | `adb -P 5038 server-status` | 4000 ms |
| 重启服务 | `adb -P 5038 kill-server` / `start-server` | 6000 / 8000 ms |

## 3. 已复刻的关键行为

- **二维码**：内容格式 `WIFI:T:ADB;S:studio-<10 位小写 hex>;P:<10 位大写 hex>;;`，两分钟有效；扫描后手机广播同名 `_adb-tls-pairing._tcp`，扩展发现后调用 `adb pair` 并在 stdout 中匹配 `Successfully paired to … [guid=…]`。
- **配对码**：6 位数字校验；优先使用 mDNS 发现的配对地址（排除 `studio-` 前缀的自身二维码服务）；未发现时允许手工填写 IP:端口 / [IPv6]:端口。
- **历史先显示**：先同步读取 `.android\adb_known_hosts.pb`（手工 protobuf wire-format 解析，失败回退 `mdns list-known-hosts --proto-text`），再查设备 / mDNS；读取失败时保留本次已读取的历史并报告失败。
- **设备合并**：查询 `getprop ro.serialno` 作为硬件身份（按 `serial + transport_id` 缓存，失败 30 秒后重试），同一硬件的 mDNS / IP / 历史记录合并为一行；无硬件序列号时按地址或传输标识合并。
- **端口变化恢复**：连接优先使用当前 mDNS 发现的地址；本次运行读到的地址只保存在内存（`sessionEndpoints`），旧地址失败一次后作废并继续等待新端口；历史设备连接最多 5 次发现重试，同一地址只尝试一次。
- **解除配对**：确认后重新刷新并确认设备仍未连接，只删除 `adb_known_hosts.pb` 中该 GUID 的记录；写入同目录临时文件并 fsync，确认原文件未被并发修改后原子替换，其它记录保持原字节不变。
- **ADB 服务**：默认端口 5038（避开 ADB 默认 5037，可在 `adbWifi.serverPort` 修改）；重启按当前端口执行，会短暂影响使用同一端口的 ADB 连接；mDNS 监听断线后 8 秒重试。
- **不做后台自动连接**：核对原源码后确认 1.3.7.0 没有后台自动 `adb connect`，本扩展同样不添加该行为；只有配对成功后的 4 次 × 900 ms 连接确认。

## 4. 有意的差异 / 简化

| 项目 | 原工具 | 本扩展 | 原因 |
| --- | --- | --- | --- |
| 界面 | 单窗口四列表格、动态列宽、窄窗口按钮换行 | 主面板 Webview 左右分栏 + 侧边栏 Webview 富卡片 | 与桌面工具一致：左侧设备、右侧配对与连接、底部状态栏；窄视图自动改为上下排列 |
| 配对地址输入 | IPv4 四格 + IPv6 单格 + 粘贴拆分 + 网段自动补全 + 编辑保护 | 同左（Webview 实现），编辑保护为"用户编辑后不再自动覆盖" | 交互等价，细节由前端实现 |
| 局域网前缀 | 检查默认网关且恰好一个 /24 | 非回环、掩码 255.255.255.0 且恰好一个 /24（不检查网关） | Node 侧无法便捷读取网关；仅用于输入提示 |
| 诊断中的 ADB 进程 | 进程 ID + 可执行文件完整路径 | `tasklist` 输出 PID + 映像名 | 跨进程读取模块路径需要额外系统权限；诊断其余内容保留 |
| 配置项 | 无（PATH ADB、固定端口） | `adbWifi.refreshInterval`、`adbWifi.adbPath`、`adbWifi.serverPort` | ADB 路径默认从环境变量 / PATH 查找，端口默认 5038；设备品牌 / 型号资料保存在 VS Code globalState |
| 二维码生成 | 内嵌 .NET QRCoder 1.8.1 | 内置 `qrcode-generator` 1.4.4（MIT），SVG 输出 | 避免 VSIX 运行时依赖 `node_modules`；二维码内容格式不变 |
| 历史记录 | 不建立工具私有历史 | 同左；只用内存缓存，唯一磁盘写入是解除配对 | 保持约束 |
| 刷新节流 | 正常 2s、二维码 0s、失败 8s、断开 / 解除配对后 5s | 同左（后台 1s tick 检查下一次刷新时间） | 一致 |

## 5. 未验证 / 待办

- 真实 VS Code 窗口中打开 Webview 面板、CSP、主题变量与中文渲染待验证。
- 真实手机（Android 11+）的二维码扫码、配对码配对、连接、断开、解除配对全流程待验证。
- 原 WPF 回归基线 162 项断言不可能直接复用；本项目当前以解析 / protobuf / 合并逻辑 12 项单元测试替代，配对与 mDNS 需实机验证。
- 与原工具共享 `%USERPROFILE%\.android` 下的 ADB 密钥与配对记录；解除配对会影响同一 Windows 用户下所有 ADB 客户端（与原工具一致）。
- 打包使用 `npm run package`（`vsce package --no-dependencies --readme-path README.extension.md`），不需要探测 npm 依赖；VSIX 内的扩展介绍页来自 `README.extension.md`，与仓库 `README.md` 分开维护；详见[开发说明](./开发说明.md)。
