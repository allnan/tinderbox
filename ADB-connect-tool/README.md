# ADB 无线调试

用于 Windows 的 Android 无线调试工具，提供二维码和六位配对码配对、已配对设备管理及连接恢复。正式交付为单个 `ADB-Wireless.exe`，运行时调用系统 PATH 中的 ADB。

## 主要功能

- 二维码或配对码配对，自动发现可用地址，支持手动连接。
- 显示 ADB 已配对设备，提供连接、断开、解除配对及设备详情。
- 使用独立 ADB 服务端口 `5038`，保留其他软件使用的服务。
- 运行期地址与名称仅保存在内存中，配对历史由 ADB 管理。

## 环境要求

- Windows 10/11 和 .NET Framework 4.8。
- PATH 中可调用的 `adb.exe`。
- 支持系统无线调试的 Android 11+ 手机；电脑与手机处于同一网络。

## 快速开始

在项目根目录的 PowerShell 中构建：

```powershell
./build.ps1
```

双击生成的 `dist/ADB-Wireless.exe`，在手机开发者选项中打开“无线调试”，然后在工具中选择二维码或配对码完成配对。首次构建会下载并校验二维码依赖。
