# ADB 无线调试：使用说明

本文中的相对路径均以项目根目录为基准。

双击 `dist\ADB-Wireless.exe`。工具适用于 Windows 10/11（.NET Framework 4.8）和支持系统无线调试的 Android 11+ 手机。工具只调用 Windows `PATH` 中找到的 `adb.exe`。窗口底部显示实际路径、Platform Tools 版本和 ADB 版本；PATH 中未找到 ADB 时可点「重新检测」。更新 Windows 的 PATH 后，点击「重新检测」即可重新查找。

本工具使用本机独立 ADB 服务 `127.0.0.1:5038`，所有命令和后台 mDNS 监听统一指定该地址。其他软件可以继续使用默认的 `5037`。工具启动的后台禁用 USB 和模拟器扫描，专门管理无线调试连接；这些设置仅传给本工具的 ADB 子进程，不更改系统环境变量。窗口底部和诊断中显示独立服务地址。

## 配对和连接

1. 让电脑和手机加入同一网络，在手机开发者选项中打开「无线调试」。
2. **二维码配对**。切换到「二维码」，然后用手机无线调试页的「使用二维码配对设备」扫描。工具通过 mDNS 找到匹配的服务后会提交配对。二维码两分钟内有效，过期可以重新生成。
3. **配对码配对**。在手机上打开「使用配对码配对设备」，保持弹窗打开。工具发现唯一配对服务时自动填写地址和端口，输入 6 位配对码即可。发现多个地址时，请从下拉列表选择手机上的地址。
4. **手动连接**。如果配对后还未连接，填写手机「无线调试」**主页**上的 IP 和端口，再点「连接」。配对端口与连接端口分别取自上述两个页面。

日常使用时，关闭再开启手机的无线调试会重新创建连接服务，连接端口可以变化。工具按已配对设备标识查询当前 mDNS 地址，优先连接本次发现的端口。同一次「连接」操作中，旧地址失败后只尝试一次，并继续查找新端口。手动填写地址并连接成功后，输入框恢复自动跟随当前地址；正在编辑的地址不会被后台刷新覆盖。

当 mDNS 查询异常或连接恢复失败时，右下角提供「重启独立服务」。确认后，工具使用 PATH 中的 ADB 向 `127.0.0.1:5038` 执行 `kill-server`、`start-server`，重新发现设备。该操作只重启本工具使用的服务，本工具的无线连接会短暂中断，使用其他端口的 ADB 服务继续运行。ADB 密钥和配对记录保留。

设备列表按设备合并显示。主行显示型号、可用连接地址和设备状态，顶部按设备计数。选中设备后，在底部展开「设备与连接详情」可查看硬件序列号、每条连接的类型和完整 ADB 标识。已确认同一部手机的 mDNS 和 IP 连接会合在一行，同型号设备仍按各自的设备标识区分。

「复制 ADB 标识」复制首选连接的标识，可用于 `adb -P 5038 -s`。在命令行查看本工具连接的设备，使用 `adb -P 5038 devices -l`；不指定端口的 `adb devices` 默认查看其他软件使用的 5037。「断开无线」断开所选设备在本工具服务中的全部无线连接。已有对应地址处于已连接状态时，再点「连接」会直接显示已连接。设备标识只在本次运行中缓存。

## 历史配对和回连

历史配对优先只读 ADB 自己的 `.android\adb_known_hosts.pb`，重复 GUID 合并显示。文件无法读取时，回退到 `adb mdns list-known-hosts --proto-text`；两种读取都失败时保留本次运行中已经读到的记录，并显示读取失败。配对记录由 ADB 管理，本工具不另存设备历史。历史列表在查询连接和 mDNS 状态前显示，ADB 服务超时也不会清空历史。连接、断开和解除配对操作都在设备行内。点历史设备的「连接」会主动查询 ADB 的配对记录和 mDNS 地址，并短暂等待服务发现；发现地址后调用 `adb connect`。ADB 配对历史只保存设备 GUID，不保存上次连接的 IP 和端口。如果本次运行中 ADB 曾读到该设备的连接地址，断开后工具会仅在内存中暂存此地址，供列表的「连接」操作使用；关闭工具后立即丢弃，不写入任何文件。若本次运行从未取得地址，且 mDNS 也没有发现连接服务，列表显示「未发现连接地址」，需要从手机「无线调试」主页把 IP 和端口填入右侧连接栏。工具不保存设备地址或别名。ADB 发现手机无线调试的连接服务后，会自动尝试连接已配对设备。

已配对且未连接的设备行提供「解除配对」。ADB 命令行没有按设备移除配对记录的命令，因此工具在确认后只从 ADB 自己的 `.android\adb_known_hosts.pb` 中移除所选设备 GUID，不建立工具自己的历史文件。该操作移除本机 ADB 的记录；手机端仍可能保留此电脑的授权。需要彻底撤销手机授权时，请在手机「无线调试 → 已配对设备」中忘记此电脑。操作前会再次确认设备仍未连接，并在更新时保留其他 ADB 配对记录。

解除配对使用应用内确认窗口，默认焦点为「取消」。程序图标同时写入 EXE 文件属性和窗口标题栏，图标由 `tools\generate-icon.ps1` 生成。

使用同一套 ADB 密钥、手机的授权仍有效时，可以直接连接。独立服务仍使用当前 Windows 用户的 ADB 密钥和 ADB 自己的配对记录，不建立工具自己的历史或配置文件。这些配对数据与同一用户下的其他 ADB 服务共享；解除配对和手机端撤销授权会影响共享该授权的连接。授权失效或手机已忘记这台电脑时，需要重新配对。手机上的「已配对设备」可查看和移除授权。

二维码和自动发现依赖 mDNS。一直停在扫码等待时，可切换到配对码模式，直接填写手机弹窗的配对地址。如果已配对，可直接填写无线调试主页上的连接地址。右下角分行展示 mDNS 与配对记录状态，并随可用宽度换行。「诊断」可查看 ADB 本机配对文件读取结果、运行中的 ADB 进程路径、服务端状态、mDNS 发现结果和连接设备列表。

IPv4 地址分四格填写，端口单独一格，可按点号或 Tab 前进。地址选项可选择已发现的地址或切换 IPv6。IPv6 地址直接填在一格，支持 `::` 和 `%接口编号`，端口单独填写。完整地址也可以粘贴到任一格，由工具拆分。未发现手机时，工具会尝试补出手机 IP。若只判断出一个 `/24` 局域网网段，填写最后一格和本次端口即可。自动补全在内存中运行。

参考 [Android 无线调试文档](https://developer.android.com/tools/adb#wireless) 和 [AOSP ADB Wi-Fi 实现说明](https://android.googlesource.com/platform/packages/modules/adb/+/HEAD/docs/dev/adb_wifi.md)。
