# Codex 用量预测：插件组件

本目录是可安装的 Node stdio MCP 插件，包含 `plugin.json`、`mcp.json`、服务、界面、算法与测试。项目根目录及本地市场入口见[项目首页](../../README.md)。

| 入口 | 用途 |
| --- | --- |
| `usage.dashboard` | 打开额度预测面板。 |
| `usage.read` | 刷新额度快照。 |
| `server.mjs` | 由 `mcp.json` 通过 `${PLUGIN_ROOT}` 启动的服务入口。 |

详细文档统一维护在项目根目录的 `docs/`：

- [使用说明](../../docs/使用说明.md)：安装、图表含义和常见状态。
- [开发说明](../../docs/开发说明.md)：源码入口、技术约束和验证方式。
- [额度预算算法](../../docs/额度预算算法.md)：数据、公式和适用限制。
