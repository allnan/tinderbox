# 使用说明

> 面向想运行演示页或在自己的项目里使用取色器的人。设计背景见 [设计方案](./设计方案.md)，构建与实现见 [开发说明](./开发说明.md)。

## 1. 运行演示页

演示页覆盖触发色块、全彩 / 色块 / 面板三种模式、主题切换和色域图展示。

```powershell
# 在 color-picker 目录执行
npm install --ignore-scripts --cache .npm-cache
npm run check       # 类型检查 + 构建 + 12 项测试 + 演示页构建与冒烟
npm run serve       # 启动静态服务
```

浏览器打开：

- 浅色：<http://127.0.0.1:4173/>
- 深色并直接打开全彩取色器：<http://127.0.0.1:4173/?theme=dark&open=full>

也可以直接双击 `demo/index.html`（脚本是单文件 IIFE，不依赖静态服务；部分浏览器对 `file://` 的限制可能影响 localStorage）。

演示页参数：

| 参数 | 作用 |
| --- | --- |
| `?open=full` | 首次渲染就打开全彩取色器（截图/演示用） |
| `?theme=dark` | 页面与取色器使用深色主题 |

## 2. 在其他项目中使用

当前是 **React 组件库**，要求 React 18+ / React 19。包未发布到 npm，推荐用本地路径或打包产物引用。

### 2.1 本地路径引用

在目标项目的 `package.json`：

```json
{
  "dependencies": {
    "@tinderbox/color-picker": "file:../tinderbox/color-picker"
  }
}
```

在 `color-picker` 目录先构建：

```powershell
npm install --ignore-scripts --cache .npm-cache
npm run build
```

目标项目再 `npm install` 即可（`file:` 依赖会建立本地链接）。React 与 React DOM 是 peer 依赖，由目标项目自己提供。

### 2.2 打包成 tgz 安装

```powershell
cd color-picker
npm run build
npm pack
# 生成 tinderbox-color-picker-0.1.0.tgz

cd <你的项目>
npm install ../tinderbox/color-picker/tinderbox-color-picker-0.1.0.tgz
```

### 2.3 代码示例

```tsx
import { useState } from 'react'
import { ColorPicker } from '@tinderbox/color-picker'
import '@tinderbox/color-picker/styles.css'

export function BrandColorField() {
  const [color, setColor] = useState('#4F7CFF')

  return (
    <div style={{ display: 'flex', alignItems: 'center', gap: 12 }}>
      <ColorPicker value={color} onChange={setColor} storagePrefix="my-app" />
      <code>{color}</code>
    </div>
  )
}
```

要点：

- 必须引入 `@tinderbox/color-picker/styles.css`，否则只有无样式的按钮；
- `value` 必须是 `#RRGGBB` 或 `#RRGGBBAA`（大小写都接受，内部规范化成大写）；
- `onChange` 在「立即」模式下拖动就会连续触发，在「确认后」模式下点「应用」才触发；
- 同一页面有多个取色器时，给它们不同的 `storagePrefix`，避免共享「默认方式 / 最近颜色」。

## 3. Props

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `value` | `string` | — | 当前颜色，`#RRGGBB` 或 `#RRGGBBAA` |
| `onChange` | `(hex: string) => void` | — | 颜色变化回调 |
| `disabled` | `boolean` | `false` | 禁用触发色块 |
| `size` | `number` | `46` | 触发色块边长（像素） |
| `className` | `string` | — | 附加到触发按钮的类名 |
| `showTriggerLabel` | `boolean` | `false` | 触发块右侧是否显示 HEX 文本 |
| `storagePrefix` | `string` | `color-picker` | localStorage 键前缀 |
| `accentColor` | `string` | 读 `--accent`，回退 `#4F7CFF` | 锁定取色器内部的强调色 |
| `defaultOpen` | `boolean` | `false` | 首次渲染就打开（演示 / 截图） |
| `onOpenChange` | `(open: boolean) => void` | — | 打开 / 关闭回调 |
| `defaultMode` | `'panel' \| 'full' \| 'grid'` | `'full'` | 没有本地偏好时的默认取色方式 |
| `defaultApplyMode` | `'live' \| 'confirm'` | `'confirm'` | 没有本地偏好时的默认应用方式 |
| `theme` | `'auto' \| 'light' \| 'dark'` | `'auto'` | 内置主题；宿主变量优先 |
| `vividColors` | `readonly string[]` | 12 个高饱和色 | 自定义「常用」色板 |
| `neutralColors` | `readonly string[]` | 10 个灰阶 | 自定义「中性」色板 |
| `maxRecent` | `number` | `12` | 「最近」颜色上限 |

`defaultMode` / `defaultApplyMode` 只在 **localStorage 里没有保存过偏好** 时生效；用户点过 pin 或切换过应用方式后，以存储的偏好为准（这是设计行为，避免每次打开都被 Props 覆盖）。

## 4. 主题与样式令牌

组件样式使用 `--cp-*` 变量。默认会优先读取宿主已有的设计系统变量，读不到时使用内置浅色/深色默认值：

| 组件令牌 | 宿主回退变量 | 浅色默认 |
| --- | --- | --- |
| `--cp-bg` | `--bg-elevated` | `#FFFFFF` |
| `--cp-bg-input` | `--bg-input` | `#F1F4F9` |
| `--cp-bg-panel` | `--bg-panel-2` | `#F6F8FC` |
| `--cp-bg-hover` | `--bg-hover` | `rgba(15,23,42,.04)` |
| `--cp-border` | `--border` | `rgba(15,23,42,.08)` |
| `--cp-border-strong` | `--border-strong` | `rgba(15,23,42,.16)` |
| `--cp-text-1` | `--text-1` | `#101623` |
| `--cp-text-2` | `--text-2` | `#5B6675` |
| `--cp-text-3` | `--text-3` | `#8B95A5` |
| `--cp-shadow` | `--shadow-pop` | 大范围柔和阴影 |
| `--cp-accent` | 无（由 Props / `--accent` 决定） | `#4F7CFF` |

直接覆盖令牌即可换肤：

```css
/* 全局或取色器所在页面 */
:root {
  --cp-bg: #fffdf7;
  --cp-border: #e7ddc8;
  --cp-text-1: #2b2418;
  --cp-accent: #c2410c;
}
```

也可以复用宿主变量：

```css
:root {
  --bg-elevated: #fffdf7;
  --border: #e7ddc8;
  --text-1: #2b2418;
  --accent: #c2410c;
}
```

注意：

- **浮层通过 portal 挂到 `document.body`**，所以宿主变量必须定义在 `:root` / `body` 上；定义在页面局部容器里的变量不会传进浮层。
- `theme="dark"` 只是启用内置深色默认值；如果宿主已定义上述变量，以宿主为准。
- 强调色在打开取色器时锁定；之后修改 `accentColor` 或 `--accent` 不会影响已经打开的取色器（这是刻意的控件行为）。

## 5. Electron / Tauri 接入

两者都是「跑网页的宿主」，不需要单独做适配库：

- **Electron**：渲染进程引入组件与样式即可。`EyeDropper` 在 Chromium 中可用，屏幕吸管按钮会出现；`contextIsolation: true` + `nodeIntegration: false` 不影响组件。
- **Tauri**：Windows 上使用 WebView2（Chromium 内核），CSS、Canvas、指针事件与 localStorage 行为基本一致；`EyeDropper` 是否可用取决于 WebView2 版本，不可用时按钮自动隐藏，其余功能不受影响。
- 桌面端如果禁用了 localStorage（隐私模式/自定义协议限制），默认方式与最近颜色退化为会话内默认值，取色本身仍可用。

## 6. 数据与偏好

| 键（默认前缀） | 内容 |
| --- | --- |
| `color-picker:color-picker-default-mode` | 默认取色方式 `panel` / `full` / `grid` |
| `color-picker:color-picker-apply-mode` | 应用方式 `live` / `confirm` |
| `color-picker:recent-colors` | 最近颜色（JSON 数组，最多 `maxRecent` 条） |

- 传入 `storagePrefix="palette-studio"` 时，键名与配色工坊完全一致，可直接沿用旧偏好；
- 清除这些键即可恢复「首次使用」状态（默认全彩 + 确认后）；
- localStorage 不可用时静默降级，不抛错。

## 7. 纯函数色彩工具

包还导出 `./core` 入口，不依赖 React / DOM，可用于 Node、脚本或其他 UI：

```ts
import {
  normalizeHex,
  hexToRgb,
  rgbToHex,
  hexToOklch,
  oklchToHex,
  contrastRatio,
  colorDisplayName,
  computeSpectrumRgba,
} from '@tinderbox/color-picker/core'

normalizeHex('#0097bb')        // '#0097BB'
colorDisplayName('#0000FF')    // '靛蓝'
contrastRatio('#000', '#fff')  // 21
```

主要导出：

- 解析 / 规范化：`parseColor`、`parseColorAlpha`、`normalizeHex`、`normalizeColor`、`alphaOf`；
- 转换：`hexToRgb`、`rgbToHex`、`hexToHsl`、`hslToHex`、`rgbToOklch`、`oklchToHex`；
- 调整：`mix`、`lighten`、`darken`、`rotateHue`、`adjustSaturation`、`withAlpha`；
- 可读性：`relativeLuminance`、`contrastRatio`、`bestTextOn`、`getContrastResult`；
- 色名：`colorDisplayName`、`COLOR_FAMILIES`；
- 全彩：`maxChromaAt`、`computeChromaField`、`smoothChromaField`、`computeSpectrumRgba`、`SPECTRUM_WIDTH`、`SPECTRUM_HEIGHT`。

## 8. 交互速查

| 操作 | 结果 |
| --- | --- |
| 点击触发色块 | 打开 / 关闭浮层 |
| 点外部 / `Esc` | 关闭浮层（确认模式丢弃未应用改动） |
| 点 tab | 切换面板 / 全彩 / 色块 |
| 点 tab 上的图钉 | 把该方式设为下次默认 |
| 点当前颜色色块 | 展开 / 收起颜色小窗（中文色名 + HEX） |
| 点「恢复」 | 回到打开取色器时的颜色 |
| 拖动透明度条 / 输入 A | 调整透明度，输出 8 位 HEX |
| 输入 HEX / RGB | 失焦或回车生效；非法 HEX 回退 |
| 点色板色块 | 立即选中，并记录到「最近」 |
| 「立即 / 确认后」 | 切换写回时机，按 localStorage 记忆 |
| 确认模式点「应用」 | 写回并关闭；「取消」丢弃 |

## 9. 常见问题

**样式全丢或浮层透明**：没有引入 `styles.css`，或宿主 CSS 重置了 `button` / `input` 的 `all`。

**浮层被遮挡**：浮层 `z-index: 150`；如果宿主有更高的弹层，需要包一层更高的层级或调整 z-index（目前没有暴露该 Props，可提需求）。

**深色主题不生效**：宿主定义了 `--bg-elevated` 等变量但仍是浅色值；此时以宿主变量为准，需要同时改宿主变量，或直接覆盖 `--cp-*`。

**屏幕上没有吸管按钮**：运行环境没有 `window.EyeDropper`（部分 WebView / 浏览器不支持），属于正常降级。

**确认模式选了颜色但页面没变**：确认模式下需要点底部的「应用」；想选完即生效，把应用方式切到「立即」。

**多个取色器互相影响默认方式/最近颜色**：它们共用了 `storagePrefix`；传不同的前缀即可。

**颜色小窗色名不理想**：中文色名是 12 色系 + 灰阶的粗分类（设计如此），不是精确色名库；需要更细的命名可在应用层另行实现。
