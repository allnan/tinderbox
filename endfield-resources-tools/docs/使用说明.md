# 使用说明

## Windows 便携版

解压完整便携文件夹，在可读写的位置运行 `endfield_resources_tools.exe`。必须保留 EXE、同目录 DLL 和 `data/` 文件夹；移动或备份时复制整个文件夹。

程序包可由源码构建：在项目根目录依次执行 `flutter build windows --release` 和 `./tool/package_portable.ps1`。ZIP 中包含运行所需文件与本说明、换算规则，不包含账本数据。

## Android

Android 版本使用应用私有存储保存账本。更新应用时保留应用数据；卸载或清除应用数据会影响本机记录。可通过局域网同步到 Windows 端保存副本。

## 记录资源

1. 输入特许寻访凭证、衍质源石、嵌晶玉和武库配额。
2. 在“源石计入”中选择角色、武库或保留；同一份源石只按所选用途计算一次。
3. 游戏日按设备本地时间每天 04:00 切换。
4. 输入、切换用途和预览不会保存。点击“保存记录”或按 Ctrl+S 后，余额才写入账本。
5. 无备注记录更新当天默认记录；填写备注会另存独立记录。

角色与武库抽数的换算、井数和趋势统计口径见[换算与记录规则](./换算与记录规则.md)。

## 查看历史与图表

总览显示资源余额与抽数。资源波动图可选择四项资源、余额走势或区间净变化，以及近 7 天、近 30 天或全部范围。日趋势使用每个游戏日最后一条有效记录；隔日记录的变化属于整个间隔，图表标记的是净变化。

备注记录、记录排除和删除会影响对应游戏日的有效汇总；移除当天最后一条有效记录后，图表回退到前一条有效记录。

## 局域网同步

1. 将两台设备连接到同一局域网并打开账本；手机保持在前台。
2. 在任一端打开“局域网同步”，选择另一台设备。
3. 同步前保存或还原尚未保存的输入。两端按最新已保存记录更新，图表日汇总另行合并。
4. 2.7.3 两端会分别报告最新记录已发送、已接收或本次无更新，并显示本机和对端实际变化的游戏日数。旧版对端仍可使用原同步数据格式，但不能提供完整的对端更新回执。

同步数据在局域网内直连传输，不经过项目服务器。若 Windows 防火墙询问网络访问权限，只在信任当前网络时允许专用网络访问。同步自动发现和跨设备行为的验证边界见[验证记录](./验证记录.md)。

## 数据位置与备份

- Windows 在 EXE 同级目录保存 `endfield_resources.json`、`.bak` 备份、临时文件、锁文件和损坏数据副本。备份 Windows 数据时复制完整便携文件夹。
- Android 数据位于应用私有的 no-backup 存储中，不是便携文件夹的一部分。
- 迁移前请先退出程序并另存账本备份。仓库忽略运行账本和发布目录；不得将实际账本、备份、锁文件或含真实余额的截图提交到仓库。

旧格式读取不会在启动时改写原件。首次保存升级后的格式会保留 `.pre-v2.bak`；损坏数据恢复时会保留损坏原件。保存失败时应先核对备份，不要手动删除原文件。
