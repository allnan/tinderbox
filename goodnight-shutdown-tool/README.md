# 晚安 · 定时关机

Windows 桌面工具，可按倒计时或指定日期与时间安排关机，并在执行前取消。当前源码版本为 1.1.0.0。

## 功能

- 支持倒计时和指定日期、时刻两种方式，分别预览剩余时长与关机时刻。
- 支持取消计划、系统托盘操作和演示模式。
- 关机请求始终设置为强制关闭应用且不重启；未保存内容可能丢失。
- 双击程序时由 Windows 按 UAC 策略请求管理员授权。
- 无需安装应用或生成配置文件。项目源码可构建为单个 EXE。

## 环境与快速开始

- 运行环境：Windows 10/11，需启用 .NET Framework 4.x 桌面组件。
- 构建环境：Windows PowerShell 与 .NET Framework C# 编译器。
- 在项目目录打开 PowerShell 并运行：

  ```powershell
  .\build.ps1
  ```

  构建结果位于 `交付/晚安·定时关机.exe`。构建产物和验证输出由项目 `.gitignore` 排除，不纳入 Git。

双击 EXE 后按 Windows 提示完成授权。也可以使用 `--demo` 参数运行不会关机的演示模式：

```powershell
.\交付\晚安·定时关机.exe --demo
```

强制关机可能关闭含未保存内容的程序；设置计划前请保存工作。Windows 接受计划不代表关机最终一定完成，详细限制见使用说明。
