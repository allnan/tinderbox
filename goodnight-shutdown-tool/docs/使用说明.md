# 使用说明

## 启动

双击 `晚安·定时关机.exe`。程序清单要求管理员权限，Windows 会按本机 UAC 策略显示授权提示；标准账户可能需要管理员凭据。

本工具会强制关闭应用并关机。未保存的内容可能丢失。设定前请保存工作。

## 设置倒计时

1. 选择“倒计时”，输入小时、分钟和秒；也可以点选 15 分钟、30 分钟、1 小时或 2 小时快捷项。
2. 查看右侧预览的剩余时长与预计关机时刻。
3. 点击开始并确认。少于 1 分钟的计划会要求再次确认。

## 设置指定时间

1. 选择“指定时间”，选择日期并填写 24 小时制的小时、分钟和秒。
2. 查看分区显示的剩余时间、关机钟点和日期。
3. 确认后点击开始。过去的时间、无效输入以及夏令时中不存在或重复的本地时刻会被拒绝。

## 取消计划

- 计划生效后，可在主窗口或托盘菜单选择取消。
- 有计划时关闭或最小化窗口会将窗口收进托盘，计划继续运行。双击托盘图标或再次打开 EXE 可恢复窗口。
- 程序重启后，“取消系统关机”可以取消 Windows 当前等待中的关机或重启。这项操作可能同时取消其他程序安排的系统计划；操作前程序会说明范围并要求确认。
- Windows 已开始关机时，取消请求可能失败。界面会保留状态并显示错误。

## 演示模式

将 `--demo` 参数传给 EXE 可打开演示模式。演示模式使用模拟后端，等待倒计时结束也不会调用 Windows 关机或取消接口。

## 计划行为与限制

- 计划交由 Windows 计时；程序退出后，Windows 已接受的计划仍可能继续。程序不保存设置或任务文件。
- 计时期间程序会阻止系统自动睡眠，但屏幕仍可自动关闭。手动睡眠或休眠期间，系统无法在目标时刻执行计划。
- 强制关闭应用可能导致未保存内容丢失。
- Windows API 成功返回只代表系统接受了请求，不证明最终关机已经完成。卡住进程、驱动、服务或系统状态下的最终关机结果尚未实机验证。

## 获取程序

源码仓库不跟踪 EXE。若从源码构建，请在项目目录运行 `build.ps1`；详细环境和构建方法见[开发说明](./开发说明.md)。
