# 开发说明

## 已确认要求

- Windows 工具支持倒计时和指定日期、时刻两种关机计划，并可取消。
- 用户要求强制关闭阻塞关机的应用、采用现代化界面，并将程序做成无需安装及配置文件的单 EXE。
- 后续确认双击启动应自动请求管理员授权；右侧倒计时与关机时刻应分区显示。

## 当前实现

- 程序版本：1.1.0.0，目标框架为 .NET Framework 4.0。
- `src/Program.cs` 是程序入口；加载嵌入的 XAML 窗口资源，并按普通模式或 `--demo` 参数创建 Windows 后端或纯模拟后端。单实例互斥体按 Windows 用户区分，演示与正式模式分开。
- `src/MainWindow.xaml` 和 `src/MainWindow.cs` 实现自定义样式的 WPF 界面、时间预览、状态提示与系统托盘交互。
- `src/Scheduling.cs` 校验倒计时和本地指定时刻，并使用单调时钟显示剩余时间。最长计划为 10 年；不存在或重复的夏令时本地时刻会被拒绝。
- `src/WindowsShutdown.cs` 调用 `InitiateSystemShutdownExW` 设定本机计划，并固定要求强制关闭应用、不重启；取消使用 `AbortSystemShutdownW`。调用前启用 `SeShutdownPrivilege`，结束后恢复原令牌状态。
- `src/app.manifest` 请求 `requireAdministrator` 并声明 DPI 感知设置。`build.ps1` 将 C# 源码、XAML、图标和清单编译进一个 EXE。
- 构建与运行不使用 NuGet 包或额外应用配置文件；运行依赖 Windows 提供的 .NET Framework/WPF 组件。可选图标生成脚本 `assets/create_icon.py` 仅用于修改图标，需要 Python Pillow，不参与构建。

## 构建与验证

以下命令都必须在项目目录的 PowerShell 中运行：

```powershell
.\build.ps1
```

在 `交付/` 生成单文件 `晚安·定时关机.exe`。脚本调用 Windows 安装的 .NET Framework C# 编译器；找不到该编译器时，构建会报错。

安全逻辑测试使用内存 API 记录器，不调用真实 Windows 关机或取消接口：

```powershell
.\build.ps1 -Tests
```

`-UiChecks` 会编译并启动界面验证程序及应用副本，运行于专用桌面并生成截图。测试代码以记录器替代关机与取消接口；该检查会启动应用副本。应用按当前 Windows 用户使用单实例信号，如果已有同一模式的实例，启动副本可能唤醒已有窗口，因此运行前必须确认没有对应模式的程序实例。此次整合未运行该项检查。

## 已知限制与风险

- `bForceAppsClosed=true` 会要求 Windows 强制关闭未保存内容的应用，可能造成数据丢失。
- Windows API 成功返回表示系统接受了关机请求，不保证关机最终完成。驱动、服务、系统状态或特定卡住进程造成的最终结果尚未验证。
- 计划由 Windows 保持；程序不保存计划配置。程序关闭后，已接受的系统计划可能仍会执行。
- 程序可以阻止自动睡眠；手动睡眠或休眠期间无法按时关机。
- `AbortSystemShutdownW` 作用于 Windows 当前的系统关机计划。无本工具本地计划时，取消按钮会要求用户确认其可能影响其他应用安排的计划。

## 官方接口依据

- [Microsoft：InitiateSystemShutdownExW](https://learn.microsoft.com/en-us/windows/win32/api/winreg/nf-winreg-initiatesystemshutdownexw)——强制关闭应用标志、关机权限与异步接受结果。
- [Microsoft：AbortSystemShutdownW](https://learn.microsoft.com/en-us/windows/win32/api/winreg/nf-winreg-abortsystemshutdownw)——取消本机系统计划及其权限要求。
- [Microsoft：应用清单](https://learn.microsoft.com/en-us/windows/win32/sbscs/application-manifests#trustinfo)——将应用清单嵌入 EXE。
