# 使用说明

本文面向使用者，介绍表情包仓库的导入、整理、复制、备份和常见问题。技术实现见[开发说明](./开发说明.md)。

## 1. 启动

1. 确认系统已安装 WebView2 Runtime（Windows 11 默认自带）。
2. 双击 `MemeVault.exe`，或在项目目录执行 `npm run start`。

发布版是单个便携 exe。首次启动会在 exe 同级创建 `userdata/` 保存素材、缩略图、配置和整理记录；把 exe 和 `userdata/` 一起复制即可迁移。若 exe 所在目录不可写（例如 Program Files），会自动改用 `%APPDATA%\com.tinderbox.memevault\data`；也可以在启动前用环境变量 `MEME_VAULT_DATA` 指定数据目录。

所有构建都不会显示额外的命令行窗口。若启动即闪退，可检查 `%TEMP%\meme-vault-crash.log`。

### 快速使用（最常用）

在任何程序里按 **`Ctrl+Shift+Space`**，鼠标附近会弹出紧凑的“快速使用”窗口：

- 默认显示“最近使用”，也可以切到收藏、全部或某个分类；支持输入名字/标签搜索。
- **单击表情 = 复制并收起**，直接回到聊天窗口 `Ctrl+V` 粘贴。
- 方向键移动、`Enter` 复制当前项、`Esc` 收起。
- 右上角**图钉**切换“置顶/不置顶”：默认不强制置顶；置顶后窗口会压在其他窗口上方，选择会保存到设置里。
- 如果热键被其他软件占用，可回主界面点右上角“快速使用”；热键注册失败会写入 `%TEMP%\meme-vault-quick.log`。
- 复制方式跟随设置里的“快速复制”：复制图片，或复制原始文件（保留 GIF/WebP 动画）。

## 2. 导入表情包

- **导入文件**：右上角“导入表情包”，可一次选择多张 PNG / JPG / GIF / WebP / BMP / AVIF。
- **导入文件夹**：右上角“文件夹”，选择后递归扫描，最多 2000 张。
- **拖拽**：把图片或文件夹直接拖进窗口。
- **粘贴**：`Ctrl + V` 可以把剪贴板里的图片加入素材库。

导入后素材会进入**待整理区**（状态为“待整理”），同一张图片（按内容哈希）只会保留一份。

## 3. 待整理区与可控整理

打开左侧“待整理”，可以看到两块内容：

- **待归类素材**：尚未设置分类或分组的素材。
- **整理建议**：由本地规则或 AI 生成的待确认提案。

生成建议不会立刻修改素材。确认流程如下：

1. 点击“本地规则整理”或“AI 整理”。
2. 打开“整理建议”，逐条查看建议分类、分组、标签、改名和理由；不需要的建议可以“跳过”。
3. 每条建议下方可以直接换一个分类；也可以点“全部采纳”或“全部跳过”。
4. 确认无误后点击“应用 N 条”。应用后会出现带“撤回”的提示，也可以在“整理记录”里撤回。
5. 若先选中了部分素材，再点击“本地规则整理”或“AI 整理”，只会处理选中的素材。
6. 若要整批放弃，点击“忽略提案”。

撤回默认会检查冲突：如果素材在整理之后又被手动修改过，会先列出受影响的素材，询问是否强制撤回。

### 本地规则整理

完全离线，根据文件名关键词、横竖比例、动图/大图特征，以及画面相似度生成建议。相似度来自导入时计算的 dHash，当 3 张以上画面明显相似时会建议新建“系列·xxx”分组。

### AI 整理

1. 进入“设置 → AI 整理”，打开开关。
2. 选择服务预设或手动填写兼容 OpenAI 的地址与模型，例如：
   - OpenAI：`https://api.openai.com/v1`，模型 `gpt-4o-mini`
   - 通义千问兼容模式：`https://dashscope.aliyuncs.com/compatible-mode/v1`，模型 `qwen-vl-max`
   - 智谱 GLM：`https://open.bigmodel.cn/api/paas/v4`，模型 `glm-4v-flash`
3. 填写 API Key 后点击“测试连接”，成功后再“保存 AI 设置”。
4. 回到待整理区点击“AI 整理”。每次最多送入设定数量的素材（默认 12 张），剩余素材可再次点击继续。

“发送缩略图给模型”关闭时只根据文件名和尺寸判断，适合不支持视觉的文本模型。

> API Key 以明文保存在本机 `data/settings.json`，不会写入备份包。请勿把该目录分享给他人。

## 4. 相册与拖动管理

- **相册首页**：左侧“相册”是默认首页。上方是全部/待整理/收藏和已有内容的分类相册，中间是“最近”，下方是空白相册。点相册进入素材网格，左上角返回箭头回到相册。
- **单击复制**：在相册首页的“最近”或素材网格里，单击卡片直接复制（不弹详情、不打断）。
- **查看详情**：卡片右上角的眼睛按钮，或双击打开大图预览；详情里可改名、选择分类、勾选分组、编辑标签和备注。
- **拖拽归类**：按住素材卡片拖到相册卡片、左侧分类/分组上松手，即可批量归类/加入分组；拖到“待整理”可移回。
- **多选**：点击工具栏“多选”后勾选，或按住 `Ctrl` 点选；`Shift` 点选连续范围。选中后底部出现批量操作条，可设置分类、加入分组、收藏、复制、移回待整理或删除。
- **双击**：打开大图预览，`←` / `→` 切换，`Enter` 复制当前图片。

常用快捷键：

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Shift + Space` | 呼出/收起快速使用窗口 |
| `Esc`（快速窗口） | 收起快速窗口 |
| `/` | 聚焦搜索框 |
| `Ctrl + A` | 全选当前列表 |
| `Enter` | 复制选中的第一张（图片） |
| `F` | 收藏 / 取消收藏选中项 |
| `1` – `9` | 归入第 N 个分类 |
| `Delete` | 删除选中项（可撤回） |
| `Esc` | 关闭预览 / 取消选择 |
| `Ctrl + V` | 从剪贴板导入图片 |
| `?` | 查看快捷键说明 |

## 5. 快速复制

- 最快：`Ctrl+Shift+Space` 呼出快速窗口，单击表情即可。
- 主界面：单击卡片直接复制当前设置的默认方式；悬浮卡片还可以单独选“图片”或“文件”，详情面板也有对应按钮。
- **复制图片**：以位图写入剪贴板，适合直接粘贴到聊天窗口；GIF / WebP 只保留首帧。
- **复制文件**：把原始文件放进剪贴板，粘贴到微信、QQ 等应用后仍保留 GIF 动画，也适合拖到其他程序。

复制成功会累计使用次数，方便按“使用次数”排序。

## 6. 备份与恢复

进入“备份与恢复”：

- **导出备份**：生成 `meme-vault-时间.zip`，保存在数据目录的 `backups` 文件夹，包含原图、缩略图、分类分组、整理记录。备份包中的 API Key 已脱敏。
- **从备份恢复**：选择 zip 包，按内容哈希去重后合并。分类和分组按名称合并，缺失的会自动创建。恢复动作会写进整理记录，可整批撤回。
- **本机备份列表**：可直接恢复或删除某份备份。
- **自动备份**：默认开启，每天首次启动时自动导出一份；最多保留 10 份。

建议定期把备份包复制到其他磁盘或网盘；程序不会自动上传。

## 7. 常见问题

**Q：AI 测试连接失败？**
先检查服务地址是否需要以 `/v1` 结尾、Key 是否有效、模型名是否支持视觉输入。401/403 表示鉴权失败，429 表示限流或额度不足，超时可以在设置里调大超时时间或调小批量。

**Q：撤回时提示“会产生冲突”？**
说明素材在整理后又被修改过。确认可以覆盖后续修改时，在提示框里点“强制撤回”。

**Q：复制 GIF 后不会动了？**
请使用“复制文件”，不要用“复制图片”。图片方式只能保留首帧。

**Q：启动时闪退或白屏？**
确认已安装 WebView2 Runtime；可以尝试删除数据目录中的 `webview` 子目录（只影响窗口缓存，不影响素材）。若仍无法启动，请保留 `%TEMP%\meme-vault-crash.log`（如存在）以便排查。

**Q：数据可以迁移到另一台电脑吗？**
可以。复制 exe 同级的 `userdata/` 文件夹（或整个程序文件夹），或在旧电脑导出备份包后在新电脑“从备份恢复”。注意 `settings.json` 包含 AI Key，迁移时请自行判断是否需要保留。

**Q：删除的素材去哪了？**
删除只是从素材库隐藏，原图仍在本机。可以在“整理记录”中撤回；暂未提供独立的回收站界面。
