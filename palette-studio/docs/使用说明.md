# 使用说明

> 面向使用「配色工坊」的用户。开发、构建与验收见 [开发说明](./开发说明.md)；架构与数据模型见 [项目交接](./项目交接.md)。

## 1. 运行方式

### 方式一：打包后的免安装版

本仓库只提交源码与文档，不提交打包产物。请在项目目录执行完整打包（需要 `node_modules/`、`runtime/` 与 .NET Framework，见 [开发说明](./开发说明.md)）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
```

打包完成后：

- 双击 `release/PaletteStudio/PaletteStudio.exe` 启动（也可以双击 `配色工坊.lnk`）；
- `PaletteStudio.exe` 是一只极小的启动器，会自动以兼容参数拉起真正的程序主体（`PaletteStudioCore.exe`），并清除宿主环境可能注入的干扰变量；如果启动失败会弹窗提示并写入同目录的 `启动日志.log`；
- 如果提示启动失败：先看 `启动日志.log`，再尝试 `启动（兼容模式）.cmd`（直接调用程序主体）；
- 想放到桌面：双击 `创建桌面快捷方式.cmd` 一键创建；
- 便携版压缩包位于 `release/配色工坊-<版本>-win64.zip`，解压即用，不写注册表。

> 说明：部分受限 Windows 会话（远程桌面、企业管控终端、自动化运行器）中 Chromium 子进程沙箱无法初始化，程序主体必须带 `--no-sandbox` 参数启动——启动器已经自动处理好，正常环境下无需任何额外操作。

首次启动会自动创建示例项目，数据默认保存在 `%APPDATA%\PaletteStudio\data\palette-studio.json`；如果该位置不可写（常见于受限 Windows 会话），应用会自动改用程序目录下的 `userdata\` 便携数据目录，并在后续启动中继续使用它（以应用内「设置 → 数据与存储」显示的路径为准）。

### 方式二：从源码运行（开发）

前置条件：Windows 10/11 x64、Node.js 22+、npm 11+，以及项目根目录下的 Electron 运行时 `runtime/`（Electron 44.x win32-x64；仓库不提交，需自行准备，见 [项目交接](./项目交接.md) 第 2.2 节）。

```powershell
# 1. 安装依赖（受限环境必须带 --ignore-scripts --cache .npm-cache）
npm install --ignore-scripts --cache .npm-cache

# 2. 构建渲染进程
node scripts/build.mjs

# 3. 启动应用（等价于直接运行 .\runtime\PaletteStudio.exe .）
powershell -File scripts/dev.ps1 -SkipBuild
```

也可以使用 `powershell -File scripts/dev.ps1` 一键构建并启动。Electron 在受限沙箱中可能无法启动，此时请使用打包版或具有完整桌面权限的环境。

## 2. 界面与基本操作

1. **新建项目**：项目总览 → 新建项目，填写名称并选择品牌主色，应用会自动生成推荐色板与语义主题。
2. **色板**：修改主色；选择 8 种配色方案之一并「添加到色板」（锁定色会被保留）；管理色板颜色；查看 50–950 明暗色阶。
3. **主题**：选择主题生成方式后点击「生成主题」，查看 18 个语义 Token 与 8 组色阶；在「界面预览」中切换桌面端/手机端，可打开右侧停靠预览面板（边改边看）或独立窗口实时对照。
4. **控件配色**：选择控件 → 在右侧为每个属性绑定颜色 → 中间实时预览。
5. **对比度**：选择前景/背景色检查 WCAG 等级，或查看项目常用组合体检结果。
6. **导出**：选择格式与选项，复制或保存代码到前端工程。
7. **记录**：保存当前配色快照，可随时恢复。
8. **设置**：查看数据位置、导出/导入全部数据、切换界面主题等。

项目总览支持新建 / 重命名 / 复制 / 删除项目，并展示配色缩略与统计。

## 3. 取色器

所有颜色输入统一使用应用内自研取色器（不调用 Windows 系统取色弹窗）。同一面板内置「面板 / 全彩 / 色块」三种取色方式：

- **面板模式**：SV 面板 + 色相条，适合同色系精细微调；
- **全彩模式（首次使用默认）**：整块 OKLCH 全色域矩形（横向色相、纵向感知明度），点哪取哪；
- **色块模式**：12 色相 × 5 档明度 + 灰阶，单击即选，不用拖滑条。

其他操作：

- 点击左上角**当前颜色块**可展开「颜色小窗」：大色块 + 中文色名 + HEX，再点收起；
- 每个取色方式 tab 上方的 pin：点当前 tab 的 pin 可把该方式设为下次默认；
- **恢复**按钮：回到打开取色器时的初始颜色（未改动时置灰）；
- **应用方式**：确认后同步（首次使用默认，点「应用」才写回，取消/Esc 丢弃）或立即同步（选色即写回），偏好自动记忆；
- 支持透明度（#RRGGBBAA）：透明度滑条、A 数值、棋盘格预览；对比度按叠加后计算；
- HEX / RGB(A) 双向输入、实时 OKLCH 读数、屏幕吸管取色。

完整的设计目标、交互规则与全彩（OKLCH 色域图）实现原理见 [取色器说明](./取色器说明.md)。

## 4. 界面预览

用当前主题渲染迷你前端界面，检查颜色层级与可读性：

- 支持「桌面网页端 / 手机端」双形态切换，浅色 / 深色模式实时切换；
- 三种查看方式：主题页内嵌、「放大预览」右侧停靠面板（主界面自动让位、不遮挡、可拖动调宽、可边改边看）、独立预览窗口（实时同步主题与设备，可在第二块屏幕上对照）；
- 工作台顶部的「界面预览」按钮可随时打开停靠预览面板。

## 5. 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + N` | 新建项目 |
| `Ctrl + 1` ~ `Ctrl + 6` | 切换工作台标签页（色板/主题/控件/对比度/导出/记录） |
| `Esc` | 关闭弹窗 |

## 6. 数据与备份

- 所有数据仅保存在本机，不上传任何服务器；
- 保存采用「先备份、再原子写入」，异常时可从备份恢复；
- 数据默认位于 `%APPDATA%\PaletteStudio\data\palette-studio.json`，受限环境下回退到程序目录 `userdata\data\palette-studio.json`；
- 设置页支持一键导出/导入全部数据（JSON）；
- 快照保留最近 60 条，重新生成主题前可选择自动保存。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 双击 `PaletteStudio.exe` 没反应或闪退 | 查看同目录 `启动日志.log`；再尝试 `启动（兼容模式）.cmd`；确认 zip 已完整解压 |
| 启动报错码 `0xC0000003` | 受限会话中 Chromium 沙箱无法初始化；启动器已自动带 `--no-sandbox`，如仍失败请用兼容模式或换正常桌面环境 |
| 数据没有保存 / 提示 `Lock file can not be created 0x5` | 默认数据目录不可写，启动器会自动回退到程序目录 `userdata\`；以「设置 → 数据与存储」显示的路径为准 |
| 从源码运行提示找不到 Electron 运行时 | 项目根目录缺少 `runtime/`，需放入 Electron 44.x win32-x64 运行时（主体命名为 `PaletteStudio.exe`） |
| `npm install` 报 EPERM | 使用 `npm install --ignore-scripts --cache .npm-cache` |
| 取色时弹出系统灰白取色器 | 属于旧版/异常情况；正常版本所有颜色输入应使用应用内取色器，如仍出现请反馈 |
| 独立预览窗口空白 | 需先在项目工作台打开项目并生成主题；确认 `dist/` 已构建、主窗口已启动 |

已知限制：仅中文界面；便携版不写注册表、无自动更新；主题 Token 只能整主题重新生成，不能单独微调；界面预览只反映主题 Token，不渲染控件配色的真实组合。更多架构与限制见 [项目交接](./项目交接.md) 第 12 节。
