## 1.0.0 — 2026-11-06（功能更新，版本号未变）

### 新增功能

- **界面预览大升级**（主题页）：
  - 支持 **桌面网页端 / 手机端** 两种设备形态切换，颜色全部来自当前主题 token；
  - 新增 **右侧停靠预览面板**：从窗口右侧向外展开，**主界面自动让出宽度（不遮挡、无遮罩）**，侧栏自动收起，可拖动左边缘调整宽度；打开后仍可继续在主窗口里改主题、切模式，预览实时刷新；
  - 新增 **独立预览窗口**：主题页或停靠面板中的「独立窗口」按钮打开，主题、明暗模式、设备形态与主窗口**实时双向同步**（可在第二块屏幕上对照）；
  - 预览面板从主题页底部上移至「语义主题」之后，打开主题页即可看到；
  - 预览图例、正文/主按钮对比度徽标在停靠面板与独立窗口中保留。
- 设置新增 `previewDevice`（桌面端/手机端），随应用数据持久化。

### 新增功能（取色器升级，版本号未变）

- 移除 Windows 系统原生颜色弹窗（灰白复古样式），新增自研现代取色器 `ColorPicker`：
  - 饱和度/明度二维面板 + 色相条，指针拖拽实时取色；
  - HEX 输入（回车/失焦提交）、RGB 三通道数值输入、实时 OKLCH 读数；
  - 常用颜色预设（暖色/冷色/中性 3 组共 32 色）、最近使用记录（localStorage，跨会话保留）；
  - 屏幕吸管（Chromium EyeDropper API，支持则显示）；
  - 点击外部或 Esc 关闭，浮层自动避让窗口边缘。
- 支持透明度（alpha）：
  - 取色器新增透明度滑条 + A 数值输入，颜色以 `#RRGGBBAA` 存储（不透明时仍为 `#RRGGBB`，旧数据完全兼容）；
  - 对比度自动先把半透明前景叠加到背景再计算；
  - HEX/RGB/HSL/OKLCH 复制与导出在带透明度时输出 rgba / hsla / oklch(... /A)；
  - 数据版本提升到 2（仅扩展颜色字符串，normalizeAppData 自动兼容旧数据）。
- 紧凑化改版：面板高度从约 560px 降到约 326px；常用 / 中性 / 最近色板改为单行小标签切换，不再占据大块空间。
- 新增「面板 / 全彩 / 色块」三种取色方式，同一面板内切换（顺序与界面一致）：
  - 面板模式：SV 面板 + 色相条，适合同色系内的精细微调；
  - 全彩模式：整块 OKLCH 全色域矩形（横向色相、纵向感知明度），每个像素都是该 (L, H) 下 sRGB 可显示的最饱和颜色，上白→中鲜艳→下黑，比传统 HSV 色带明度更均匀；点哪取哪；
  - 色块模式（默认）：12 色相 × 5 档明度 + 12 档灰阶的格子色板，单击色块即选，不需要拖任何滑条；
  - 修复纯黑/纯白的中文色名：不再叫「深灰/浅灰」，分别改为「黑色/白色」（含 nameWithLevel 生成名）。
- 修复不透明颜色块仍显示透明度棋盘格的问题：棋盘格改为垫在颜色下层，只有当前颜色真正半透明时才透出网格。
- 修复全彩色域图最底行出现 #010000 / #000002 之类杂色的问题：L≈0 / L≈1 的行强制纯黑/纯白，且上下边缘 2px 取色吸附到纯黑/纯白。
- 取色器新增「颜色小窗」：点击左上角当前颜色块浮层展开；外壳使用与取色器弹窗相同的背景色变量（浅色主题为白、深色主题为深灰）+ 细边框（2px 内边距）+ 阴影，顶部与取色器对齐，内部为 132×132 方形色块（中文色名 + HEX）；默认浮在取色器左侧（空间不足时放右侧），不占用布局空间、不改变面板高度；再点收起，关闭取色器时自动收起。
- 全彩取色图渲染升级：720×360 高分辨率 + Bayer 抖动消除渐变条带，并对最大色度场做轻微平滑（色相环绕），使蓝紫区 sRGB 色域凹口的过渡更自然；面板/全彩/SV 取色区域使用 4px 小圆角。
- 修复全彩色域图光标在顶部/底部拖动时只跳不跟随：光标改为直接记录指针的色相/明度，不再从接近黑/白颜色反推；小圆圈始终跟随指针并完整显示、不被面板裁剪（实测与指针偏差 0px）。
- 取色区域（全彩面板、SV 面板、色块网格）使用 4px 小圆角（此前曾改为直角）；顶部当前/初始颜色输入框保持圆角。
- 修复全彩边缘圆圈无法按住拖动：面板外圈增加 8px 可拖拽命中区、圆圈恢复不拦截指针，露在面板外侧时按下也能拖（实测偏差 0px）。
- 修复点「恢复」后全彩光标不跟随：颜色同步时（非拖动状态下）光标会移动到该颜色对应的位置。
- 取色器色块容器内边距统一：左右与上下均 5px。
- 取色器细节修正：确认模式底部操作条去掉「未同步：#HEX」提示（只保留右对齐的取消/应用）；「应用方式」分段控件改为均匀内边距与间距；取色器标题区顺序定为「当前颜色 → 初始颜色（色块+色值）→ 恢复按钮 → 吸管」：恢复按钮紧挨初始颜色右侧、吸管在最右；当前与初始色块统一 24px、色值字号统一 11.5px；恢复按钮未改动置灰、改动后点亮，固定占位避免面板尺寸变化；面板宽度 300→340。
- 取色器头部「当前颜色 / 初始颜色」色块从 18px 加大到 24px，色块区高度 34px，颜色更易辨识。
- 取色器「当前颜色 / 初始颜色」：标题区将「选中颜色（色块 + 可编辑色值）」与「初始颜色（色块 + 色值）」并排为两个平级区域；打开时记住带入颜色，改动后出现初始颜色区域，点击即恢复到最初颜色；立即模式同时恢复外部输入，确认模式只恢复内部待应用颜色。
- 修复取色器内部控件颜色跟随正在编辑的颜色变化：打开取色器时锁定当时的强调色，pin、当前 tab、初始颜色区域等不再随选色变色。
- 取色方式支持「pin 设默认」：每个 tab 右侧有上下居中的 pin，点当前 tab 的 pin 即把它设为下次默认打开的方式（localStorage 记忆）；被 pin 的 tab 即使未选中也显示高亮 pin（略降透明度、仍清晰可辨），其它 tab 默认不显示；未 pin 的当前 tab 悬停时才浮出 pin。
- 新增「应用方式」设置（取色器面板内，与「设为默认」并排，自动记忆）：
  - **立即同步（默认）**：选色过程中实时写回外部输入；
  - **确认后同步**：取色器内部先预览，底部出现「取消 / 应用」，点「应用」才写回；Esc、点击外部或「取消」都丢弃未应用改动。
- 覆盖所有颜色输入入口：色板「添加颜色」/主色编辑、新建项目、编辑项目、对比度取色、控件配色自定义颜色。

## 1.0.0 — 2026-11-06

首个完整可用版本（Windows 便携版，Electron 44 + React 19 + TypeScript）。

### 新增功能

- **多项目管理**：项目总览（搜索、统计、配色缩略卡片）、新建/编辑/复制/删除项目；每个项目独立主色、色板、主题、控件配色与快照。
- **配色生成**：
  - 8 种和谐配色：互补色、相邻色、三角配色、分裂互补、四角配色、单色明暗、暗调、亮调；
  - 一键推荐 17 色色板，自动中文色名（如「靛蓝 500」）；
  - OKLCH 感知均匀的 50–950 明暗色阶（11 档），支持逐档/全部加入色板；
  - 色板管理：改名、锁定、删除（被控件引用时二次确认）、添加颜色、应用推荐色板。
- **语义主题**：
  - 主色派生 18 个语义 Token（浅色/深色两套）+ 8 组色阶；
  - 5 种生成方式：均衡、鲜艳、柔和、中性、高对比；
  - 自动保证正文 ≥ 7:1、主色按钮文字 ≥ 4.5:1 的对比度；
  - 迷你前端界面预览（导航/顶栏/统计卡/表格/表单/Toast）。
- **控件配色**：24 种前端控件、77 个属性，支持绑定主题 Token / 项目色板 / 自定义颜色；24 套真实控件实时预览；单控件/全部重置为默认；浅色/深色预览切换。
- **对比度检查**：WCAG 2.1 AA/AAA 判定、三档字号文本示例、项目常用组合体检、不达标时给出建议色。
- **导出**：7 种格式（CSS 变量 / SCSS / Tailwind v3 / Tailwind v4 / W3C Design Tokens / ES Module / Figma 变量），可选明暗模式、色阶、色板、控件、变量前缀；支持复制与保存文件。
- **配色记录**：快照保存/恢复/重命名/删除，重新生成主题前可自动快照，最多保留 60 条。
- **应用体验**：深/浅界面主题、界面强调色随项目主色变化、无边框窗口、窗口尺寸记忆、自动保存、Toast、错误边界、快捷键（Ctrl+N / Ctrl+1..6 / Esc）。
- **数据安全**：本地 JSON 存储（原子写 + 自动备份 + 备份恢复），设置页支持整体导出/导入。
