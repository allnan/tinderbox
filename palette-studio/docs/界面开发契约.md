## 一、技术约定

1. React 19 + TypeScript strict，函数组件 + hooks；不新增第三方依赖。
2. 视图由 `ProjectWorkspace.tsx` 以固定方式挂载，**必须默认导出**，props 形状固定：

```tsx
import type { ProjectViewProps } from './types'
export default function XxxView({ project, mode }: ProjectViewProps) { ... }
```

- `project`：当前项目（永远非空）。
- `mode`：`'light' | 'dark'`，当前预览的明暗模式（用户可在工作台切换）。主题/控件/对比度相关颜色都要按 mode 取值。
- 数据修改一律通过 `useApp().actions`（见下），不要直接改 props。

3. 样式：在 `src/views/` 下新建自己的 `.css` 文件（构建脚本会自动收集 `src/**/*.css` 并注入页面，无需 import、无需改 index.html）。类名使用视图前缀避免冲突：
   - PaletteView / ThemeView → `palette-*`、`theme-*`（palette-ui 负责）
   - ControlsView → `controls-*`
   - ContrastView / ExportView / HistoryView → `contrast-*`、`export-*`、`history-*`（或统一 `tools-*`）
   尽量复用设计系统已有类（`.panel` `.card` `.page-header` `.badge` `.btn` `.grid-2` …），只用 CSS 变量取色（`var(--bg-panel)` `var(--text-2)` `var(--accent)` 等），**不要写死暗色/亮色**。
4. 文案：简体中文，语气专业、简洁；操作要有反馈（toast / 空状态 / 按钮禁用）。
5. 所有可复制的颜色都用 `CopyableColor` 或 `useColorCopy()`（会按用户在设置里选的格式复制并弹 toast）。
6. 不允许修改：`src/App.tsx`、`src/components/**`、`src/state/**`、`src/core/**`、`src/shared/**`、`src/styles/**`、`electron/**`、`scripts/**`、`package.json`、`tsconfig.json`。发现自己需要的共享能力缺失时，用 `send_message` 告诉 lead。
7. 沙箱限制：不要运行 `npm install`、不要尝试启动 Electron；Node 子进程被禁用。可用脚本：`node scripts/typecheck.mjs`、`node scripts/test.mjs`、`node scripts/build.mjs`、`node scripts/dom-smoke.mjs`。


## 五、各视图功能要求

### 1. PaletteView（色板）
目标：以「主色 → 多种方案 → 色板 → 明暗色阶」为核心。
- 顶部主色卡：展示当前主色（大色块 + `ColorField` 或 HEX 输入），修改后 `actions.updateProject(project.id, { baseColor })`；提供「一键应用推荐色板」按钮（`suggestPalette` + `replacePalette`）与「重新生成主题」提示（可调用 `generateSemanticTheme` + `setTheme`）。
- 配色方案生成区：8 种 `HARMONIES` 以卡片/chip 展示（中文名 + 说明），选择方案后实时展示该方案的颜色条（`generateHarmony`）；按钮「添加到色板」（`mergeGeneratedPalette` 保留 locked 色，再 `replacePalette`）。**注意**：若色板里有 locked 颜色，要保留它们。
- 色板管理区：网格展示 `project.palette`，每个颜色卡：色块（点击复制）、名称（可双击/编辑按钮改名）、HEX（mono 字）、锁定按钮（locked 切换）、删除按钮。顶部「添加颜色」按钮（弹窗：HEX 输入 + 名称 + 可选从当前主色取）。
- 明暗色阶区：展示主色 `generateTonalScale(baseHex)` 的 50–950 色阶（`ScaleStrip`，跟随 mode），点击色块复制；每个档位可「加入色板」。
- 空状态处理：palette 为空时给出提示与添加按钮（但示例项目默认非空）。
- 视觉：信息密度高但不拥挤；使用 Panel 分区；颜色卡用 grid（auto-fill minmax 150px）。

### 2. ThemeView（主题）
- 顶部：主题生成方式选择（5 种 `THEME_METHODS`，说明文字），按钮「根据主色生成主题」（`generateSemanticTheme(project.baseColor, method)` → `actions.setTheme`）；显示当前主题元信息（主色、生成方式、token 数、色阶数）。
- 语义色 Token 网格：18 个 token，每个卡片显示中文名、token key、浅色与深色两个色块（当前 mode 高亮）、点击复制；可用 `ModeToggle` 切换查看。
- 色阶区：8 个色阶（primary/secondary/accent/neutral/success/warning/error/info），每个用 `ScaleStrip` 展示，点击复制。
- **UI 预览区**：用一个「迷你前端界面」卡片展示主题实际效果（导航栏、卡片、按钮、输入框、标签、表格行等），所有颜色取自 `theme.tokens`（按 mode 取 light/dark）。要做得真实、好看，这部分是主题视图的亮点。
- 若无主题：显示空状态 + 生成按钮。

### 3. ControlsView（控件配色）
- 布局：左侧控件列表（按 `CONTROL_CATEGORIES` 分组，24 个控件），中间大号实时预览，右侧属性配色面板。
- 控件列表项：图标（可用 Icon 近似）+ 中文名 + 已自定义属性数徽标。
- 预览：为每个控件写一个简洁的 HTML/CSS 预览（按钮、输入框、卡片、表格、导航、标签、徽章、开关、弹窗、提示条…），**用解析后的颜色**（`resolveColorRef` 或 `useControlColors`）。缺省属性要有回退色（中性灰）。
- 配色面板：遍历该控件的 `parts`，每行 `<ColorRefPicker>`（主题 token / 项目色板 / 自定义），显示解析后 HEX + 复制；「重置此控件」按钮（用 `defaultControlStyles(project.theme)` 对应绑定 + `replaceControlStyles` 局部替换）；顶部「全部重置为默认」按钮。
- 预览区支持 mode 切换颜色（props.mode）。
- 若 project.theme 为 null：仍可用色板/自定义绑定，提示先生成主题可获得默认绑定。

### 4. ContrastView（对比度）
- 前景/背景两个 `ColorField`（初始值：前景取 `text-primary` token、背景取 `background` token，或色板前两个色）。
- 大号对比度数字（如 `7.42`）+ WCAG 徽章（AA / AAA / AA 大字 / 不达标），正文/大字两种判定说明。
- 文本示例预览：在背景色上渲染「大标题 24px / 正文 14px / 小字 12px」三种字号的前景色，直观展示可读性。
- 快捷选择：从项目主题 token 和色板中点击选择前景/背景（下拉或色块列表）。
- 项目组合体检：自动检查常用组合（正文字色/页面背景、主色前景/主色、次要文字/表面、边框/表面 等 5–8 组）并列出通过/不通过；不通过时给出建议（如用 `lighten/darken` 搜索最近达标色，展示建议色块）。
- 支持交换前景/背景（`swap` 图标按钮）。

### 5. ExportView（导出）
- 格式选择：7 种 `EXPORT_OPTIONS`（CSS 变量 / SCSS / Tailwind v3 / Tailwind v4 / W3C Tokens / ES Module / Figma），以卡片网格展示（名称 + 说明 + 语言标签）。
- 选项面板：明暗模式（浅色/深色/两者 Segmented）、包含色阶、包含色板、包含控件（Switch）、CSS 变量前缀（Input，默认 `color`）。改选项实时重新生成代码。
- 代码预览：等宽字体、深色代码块、行号可选；显示代码行数/字符数；「复制代码」（`navigator.clipboard` 或 `window.desktop.writeClipboard`，用 toast 反馈）、「保存为文件」（`window.desktop.saveFile({content, defaultPath, filters})`，无 desktop 时用 Blob 下载）。
- 顶部提示：导出内容会随项目当前色板/主题实时变化；无主题时只导出色板。
- 可加「使用提示」小字（如 CSS 变量如何配合 Tailwind 使用）。

### 6. HistoryView（记录）
- 顶部说明 +「保存当前配色为记录」按钮（`actions.createSnapshot(project.id)`）。
- 列表（时间倒序）：每条显示 label、创建时间（`formatTime` / `relativeTime`）、主色色块 + 色板缩略条（前 8 色）、token 数/颜色数、操作：恢复（ConfirmDialog 确认，`restoreSnapshot`）、删除（确认）、可重命名（可选）。
- 当前状态与最新记录对比提示（可选加分）。
- 空状态：说明「重新生成主题前会自动保存快照（可在设置关闭）」。

1. `node scripts/typecheck.mjs` 0 错误（只看自己文件相关；其它人并行文件导致的临时错误请等待/复跑）。
