# TinderKit

Windows 桌面小工具集：一个常驻宿主 + 插件式工具，目标是比 PowerToys 更轻、热键呼出更快、界面统一。

> **状态：方案阶段，未开始编码。** 本目录目前只保留软件方案、技术选型和开发约定，没有可运行代码。

## 目标

- 常驻托盘，资源占用克制，空闲时接近零开销。
- 一个命令面板热键搜全部工具；每个模块还可以有自己的热键直接召唤。
- 宿主不认识任何具体工具，工具以插件形式独立增删，禁用时不加载。
- 同时提供**安装版**和**绿色版**，数据位置随分发方式区分。
- 界面走 Fluent 风格，清晰现代即可，不追求炫技。

## 技术选型

| 项 | 选择 |
| --- | --- |
| 语言与运行时 | C# / .NET 10 LTS（Windows x64） |
| 桌面框架 | WPF（主题库是否引入 WPF UI 待定） |
| 架构 | 单进程常驻宿主 + 插件程序集；插件目录扫描，`AssemblyLoadContext` 加载 |
| 分发 | 安装版（Inno Setup 6，仅构建机依赖）+ 绿色版 ZIP |
| 数据 | 绿色版：exe 同级 `data/`；安装版：`%APPDATA%\TinderKit` |

选型理由摘要：Windows 系统能力（热键、剪贴板、托盘、Shell）在 .NET 上最顺；动态插件加载是 .NET 原生能力；单语言维护成本低。WebView 方案（Tauri/Electron）UI 自由度更高，但常驻内存和长列表性能不如原生，且插件只能编译期注册，因此不作为首选。

## 入口模型

- **主界面**：导览与设置，只从托盘或重复启动打开，不绑定热键。
- **命令面板**：一个全局热键（默认 `Ctrl+Shift+Space`），搜索全部已启用模块的命令。
- **模块热键**：模块在清单里声明默认快捷键，宿主统一注册；按下打开该模块自己的面板。
- **托盘**：打开主界面、命令面板、退出。

## 计划中的模块

按优先级排列，范围待逐个确认：快速启动、剪贴板管理、表情管理、翻译。它们共享宿主的热键、托盘、设置、面板外壳与数据目录，业务互不依赖。
