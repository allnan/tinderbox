# TinderKit 使用说明（计划）

> 当前没有可运行版本。本文描述的是计划中的使用方式，随实现推进更新。

## 安装与运行（计划）

- **安装版**：运行 Setup.exe，每用户安装到 `%LOCALAPPDATA%\Programs\TinderKit`，带开始菜单与卸载项；数据在 `%APPDATA%\TinderKit`。
- **绿色版**：解压 ZIP 后直接运行 exe；数据在程序目录的 `data/`，整个文件夹可拷贝迁移。
- 两种版本都不需要管理员权限，也不要求目标机预装 .NET。

## 日常使用（计划）

| 操作 | 方式 |
| --- | --- |
| 打开主界面 | 托盘双击 / 托盘菜单；主界面只作导览与设置 |
| 命令面板 | 全局热键（默认待定），搜索全部工具命令 |
| 召唤某个模块 | 该模块自己的热键，打开模块面板 |
| 关闭浮窗 | Esc，焦点回到原窗口 |

## 设置（计划）

命令面板快捷键、模块快捷键、外观（跟随系统/浅色/深色）、开机自启（默认关闭）、数据与插件目录。
