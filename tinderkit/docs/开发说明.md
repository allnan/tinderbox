| 项 | 内容 |

## 已确认的技术约定

1. **单语言单进程**：宿主与插件都用 C#/.NET；首版不做多进程隔离，插件入口必须自行捕获异常。
2. **宿主零业务知识**：宿主只认插件清单与契约，不引用具体模块的业务类型。
3. **热键、托盘、剪贴板由宿主统一管理**：模块只能声明默认快捷键与命令，不得自行注册系统热键或创建托盘图标。
4. **主界面不是热键目标**：主界面只作导览与设置，从托盘或重复启动打开；全局热键用于命令面板或某个模块。
5. **模块面板由宿主托管**：模块只提供内容视图，窗口位置、焦点、Esc、失焦收起与复用归宿主。
6. **页面常驻**：主界面页面只创建一次，切换不重建；导航路径上不允许同步 IO。
7. **禁用即不加载**：被禁用的模块不加载程序集，停用时释放热键与面板。
8. **绿色与安装分离**：绿色版用标记文件把数据放在程序目录；安装版数据放 `%APPDATA%\TinderKit`；默认不写注册表。
9. **彩色 emoji 不使用字体渲染**：表情类模块用图片资源。
10. **不要求管理员权限**：对管理员窗口的输入注入会失败，属已知限制。

## 开发与构建（计划）

- 开发机需要 .NET 10 SDK；安装包另需 Inno Setup 6（仅构建机）。
- 构建：`dotnet build TinderKit.sln`。
- 运行：`dotnet run --project src/TinderKit.App`。
- 发布：绿色版输出 ZIP，安装版输出 Setup.exe；发布产物不提交仓库。

## 验证方式（计划）

| 指标 | 目标 |
| --- | --- |
| 待机内存（托盘 + 预热面板） | ≤70MB |
| 空闲 CPU | ≈0% |
| 热键 → 可输入 | ≤100ms |
| 已访问页切换 | ≤100ms 且有即时反馈 |
| 禁用模块 | 热键释放、面板关闭、不残留加载 |
| 绿色版 | 解压即用，数据在程序目录，可整包迁移 |
| 安装版 | 安装/卸载正常，数据在 AppData 且卸载保留 |

## 已知风险与待验证

- WPF 彩色 emoji 与精致动效的上限，需要在原型阶段确认观感是否达标。
- UIPI/前台锁对“唤出后立即输入”和后续粘贴注入的影响，需要实测。
- 单进程下某个模块崩溃会拖垮宿主，是否需要进程隔离尚未决定。
- 插件加载采用编译期内置还是目录动态加载，待首个模块完成后再定。
- 机器缺少 .NET SDK，构建与运行均未验证。
