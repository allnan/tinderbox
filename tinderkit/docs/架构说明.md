# TinderKit 架构说明

> 方案阶段文档：描述目标架构，尚未对应任何已实现代码。

## 1. 总体分层

`text
┌──────────────── 宿主（常驻、单实例）────────────────┐
│ 托盘 · 命令面板 · 全局热键 · 设置 · 日志 · 插件管理 │
│ 模块面板外壳（位置/焦点/Esc/失焦收起/复用）        │
└──────────────────▲──────────────────────────────────┘
                   │ 契约（插件清单 · 命令 · 面板）
   ┌───────────────┴─────┬─────────────┬─────────────┐
   │ 快速启动（计划）    │ 剪贴板（计划）│ 表情（计划） │
   └─────────────────────┴─────────────┴─────────────┘
`

宿主与插件只通过契约通信；插件之间不互相引用。

## 2. 宿主职责

- 单实例、托盘、开机自启（默认关闭）。
- 全局热键统一注册与冲突检测：命令面板一个，每个启用模块各一个。
- 命令面板：聚合宿主内置命令与插件命令，搜索、排序、执行。
- 模块面板外壳：窗口位置、焦点、Esc、失焦收起、预热与复用，模块只提供内容视图。
- 设置存取、日志、插件生命周期（加载/启用/停用/卸载）。

## 3. 契约草案

| 契约 | 内容 |
| --- | --- |
| 插件清单 | id、名称、描述、图标字形、版本、默认快捷键 |
| 命令 | id、标题、副标题、关键词、图标；注册到统一命令面板 |
| 命令结果 | 关闭、复制文本、插入文本、打开目标、提示、打开模块面板 |
| 设置项描述 | 键、标题、说明、类型（开关/文本/数字/选项）、默认值、选项 |
| 宿主能力 | 插件数据目录、设置读写、通知；面板形态额外提供“收起面板” |
| 模块面板 | 模块标题、图标、内容视图工厂、显示/隐藏回调 |
| 插件本体 | 清单、设置项、命令、启用/停用、执行命令 |

设计原则：契约保持小；新增工具不要求改宿主；只有新增一种“结果动作”才需要动宿主。

## 4. 入口与执行流

`text
托盘 / 重复启动 ──→ 主界面（导览与设置）
命令面板热键   ──→ 全部已启用模块的命令 ──→ 搜索 ──→ 执行结果（宿主统一落地）
模块热键       ──→ 模块自己的面板
命令面板里的模块命令 ──→ 打开对应模块面板
`

## 5. 热键模型

- 热键由宿主按 owner 统一注册（面板用固定 owner，模块用插件 id），模块停用时释放。
- 热键冲突只影响对应 owner，并给出提示；改键失败时恢复旧热键。
- 模块只声明默认快捷键，不直接调用系统 API。

## 6. 插件加载与生命周期

1. 扫描 `plugins/<id>/plugin.json`；缺清单的目录跳过。
2. 只读清单即可展示工具入口；禁用的插件不加载程序集。
3. 启用时用可回收的加载上下文加载插件程序集，契约回落默认上下文。
4. 停用时释放面板、注销热键、卸载插件实例。
5. 首版可先编译期内置，接口保留目录动态加载的可能。

## 7. 数据与分发

| 形态 | 数据位置 | 说明 |
| --- | --- | --- |
| 绿色版 | exe 同级 `data/` | 依赖 `portable.flag` 标记；整包可拷贝迁移 |
| 安装版 | `%APPDATA%\TinderKit` | 每用户安装；卸载保留用户数据 |
| 插件数据 | 上述数据根下的 `plugins/<id>/` | 每个模块自己的数据与统计 |

安装包计划用 Inno Setup 6 生成（构建机依赖，目标机不需要）。默认不写注册表；只有用户开启“开机自启”时才写当前用户启动项。

## 8. 界面基线

- Fluent 风格：统一字体、间距、圆角、图标（Segoe Fluent Icons）。
- 主界面、命令面板、模块面板共用调色板与控件样式，深/浅色跟随系统。
- 动效克制：淡入 + 轻微位移，150–200ms。
- 彩色 emoji 不使用字体渲染（WPF 不支持彩色字体），表情类工具用图片资源。
- 高 DPI：PerMonitorV2。

## 9. 性能与资源策略

- 页面常驻：主界面页面只创建一次，切换不重建。
- 命令面板与常用模块面板启动时预热隐藏窗口，避免首次弹出延迟。
- 插件禁用即不加载；窗口按需创建。
- 耗时工作（索引、图标、网络）一律后台执行；空闲时无定时器和持续重绘。
- 空闲 CPU 目标接近 0%。

## 10. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| WPF 彩色 emoji 不支持 | 表情类工具显示受限 | 图片资源方案 |
| 前台锁与 UIPI | 唤出、粘贴注入可能失败 | 保存调用前窗口句柄，失败明确提示，不整体提权 |
| 单进程崩溃 | 单个模块异常拖垮宿主 | 插件入口统一异常捕获与隔离 |
| 插件 ABI 演进 | 接口改动要重编译插件 | 契约从小处开始，版本化清单 |
| 无 .NET SDK 的机器 | 无法构建 | 开发机安装 .NET 10 SDK |

| M1 | 快速启动模块 | 未开始 |
