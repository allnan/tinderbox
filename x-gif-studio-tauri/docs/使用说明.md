# 使用说明

本说明面向使用 **X 媒体工坊 Tauri 版** 的用户。技术实现与构建方法见 [开发说明](./开发说明.md)，项目概览与截图见 [项目 README](../README.md)。

> Tauri 版是真实功能版：解析、保存、GIF/WebP 转换、工具下载、历史与设置都可用。桌面后端由 Rust 实现，前端使用 React。

## 1. 运行环境

- Windows 10 / Windows 11，64 位；
- 系统 WebView2 运行时（Windows 11 与已更新的 Windows 10 一般自带；缺失时请从微软官网安装 Microsoft Edge WebView2 Runtime）；
- 首次使用需要联网下载转换工具；之后可离线使用；
- 不需要安装 Node.js、Electron 或 ffmpeg。

## 2. 第一次使用

1. 把 `XMediaStudioTauri.exe` 放到任意可写目录（U 盘、桌面均可；建议单独建一个文件夹）；
2. 双击启动；首次启动会在 exe 同级创建 `userdata` 与 `tools`；
3. 打开「设置」→「外部工具」，点击「下载所需工具」（约 100+ MB），等待下载、解压、校验完成；
4. 工具就绪后回到「解析」，粘贴 X / Twitter 链接开始使用。

> 「下载所需工具」从各工具官方/推荐来源下载，安装到 **exe 同级的 tools 目录**，不会安装到系统目录。
>
> 工具缺失或损坏时，设置页会显示「缺失」，点击「重新下载 / 更新工具」即可。下载失败请检查网络或代理后重试。

## 3. 基本操作

### 3.1 解析推文

- 在首页粘贴 `x.com` 或 `twitter.com` 的推文链接，点击「解析」；
- 支持带查询参数、`/photo/1` 后缀、移动端链接；
- 解析失败会显示原因：推文不存在/已删除、受保护、请求频繁、网络失败等；
- 保护账号、需要登录的推文无法读取。

### 3.2 选择与保存原始媒体

- 结果页会列出推文中的图片、视频、动图媒体；
- 勾选需要的媒体，点击「保存所选」保存原始文件；
- 视频/动图原始文件是 MP4，图片保留原始格式；
- 保存位置默认是 `userdata/output`，可在设置中修改输出目录；
- 已保存的媒体显示绿色标记，可在历史记录中重新打开或定位。

### 3.3 导出 GIF / WebP

1. 在结果页勾选要转换的媒体；
2. 点击「转换为动图」打开右侧参数面板；
3. 选择输出格式 GIF 或 WebP；
4. 调整尺寸（百分比 / 像素，宽高按源比例联动）、帧率（原帧率 → 目标帧率）、质量、颜色数、平滑渐变、播放速度等；
5. 点击「开始转换」；
6. 转换完成后在「动图输出」中查看结果，可打开、定位、另存为或删除。

转换在本地执行，不把视频上传到服务器。转换期间可看到任务进度；支持取消。

### 3.4 历史记录

- 每次解析、保存、转换都会按推文链接分组保存；
- 可搜索、展开查看已保存媒体和动图结果；
- 可删除单个结果、单条媒体或整条历史；
- 删除历史时可选择是否同时删除磁盘文件。

### 3.5 设置

- **外部工具**：查看 ffmpeg / gifski / gifsicle 状态、版本与路径，一键下载/更新；
- **外观**：深色 / 浅色 / 跟随系统；
- **网络代理**：系统代理 / 自定义 HTTP·HTTPS·SOCKS5（支持认证）/ 直连，可测试连接；
- **存储**：应用数据、输出目录、缓存目录；可自定义输出/缓存位置；
- **默认导出设置**：新建转换时沿用的参数；
- 修改后点击「保存设置」生效。

## 4. 文件与目录

| 位置 | 内容 |
| --- | --- |
| exe 同级 `tools\` | ffmpeg / gifski / gifsicle，由应用下载 |
| exe 同级 `userdata\` | 设置、历史、媒体缓存、默认输出 |
| `userdata\output\` | 默认输出目录（可在设置中修改） |
| `userdata\cache\` | 临时视频、缩略图、抽帧文件 |
| `userdata\media\` | 按推文保存的原始媒体与转换结果 |

- 数据随程序目录走，移动时把 exe、`tools` 和 `userdata` 一起移动即可；
- 设置中的输出目录/缓存目录可以指向其他磁盘；
- WebView2 自身的系统缓存可能由系统管理，应用不主动写入用户文档目录。

## 5. 常见问题

**启动白屏或无法打开**
- 确认系统已安装 WebView2 Runtime；
- 尝试把 exe 放到有写权限的目录（不要放在 Program Files 根目录）；
- 检查杀毒软件是否拦截了子进程 ffmpeg/gifski。

**工具下载失败**
- 检查网络或设置代理；
- 关闭可能拦截 ZIP 下载的安全软件后重试；
- 设置页点「重新下载 / 更新工具」。

**转换失败**
- 确认工具状态为「3/3 可用」；
- 检查输出目录/缓存目录是否可写；
- 失败原因会显示在任务卡片中；可重试或换较小尺寸/帧率。

**推文解析失败**
- 确认链接是公开推文；
- 受保护、已删除、需要登录的推文无法解析；
- 网络受限时配置代理后点「刷新」。

**可以同时放多个副本吗**
- 可以。每个副本是一个独立目录，工具与 userdata 各自位于自己的 exe 同级目录。

**Windows 提示未知发布者**
- 当前 exe 未做代码签名，Windows SmartScreen 可能提示；确认来源后选择「仍要运行」。

## 6. 已知限制

- 仅 Windows 10/11 x64 验证；Linux/macOS 未验证；
- 真实解析依赖 X 的公开接口，接口变化或网络限制可能导致失败；
- 不支持需要登录/受保护的推文；
- 首次下载工具约 100+ MB，取决于网络；
- 未做自动更新与代码签名；
- 个别系统 WebView2 版本的字体/渲染可能有细微差异。
