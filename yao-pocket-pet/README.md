# 阿咬宠物机

一个手机优先的像素风虚拟宠物小应用。把参考图里的椭圆红色宠物机做成网页外壳，让像素阿咬住在屏幕中；通过触摸、喂食、梳理、陪玩和场景互动照料阿咬，并用旅记记录相伴过程。

## 主要功能

- 手机主画面以红色椭圆宠物机为主视觉，LCD 使用按用户确认形象制作的阿咬像素立绘；
- 三枚实体按键分别打开食物、互动和护理菜单；触摸阿咬不同部位可触发摸头、碰脸、挠脚和碰口水边等不同回应；
- 点 LCD 空处时阿咬会小跑过去；互动菜单提供追叶子、躲猫猫、贴贴和听阿咬说话，追墨点小游戏作为可选内容保留；
- 阿咬会在待机时眨眼、闻闻、伸展和在场景里散步；云、花和晨昏背景也会缓慢变化；
- 角色图有待机、行走、进食和睡眠四组逐帧动画；每组 4 帧，保持用户确认的阿咬轮廓和口水位置；
- 三种食物效果不同，抓墨点可获得墨点并兑换点心和深度护理；
- 饱食、心情、体力、洁净度、亲密等级、相伴天数、每日照料目标和旅记；
- 睡眠会按经过时间恢复体力，离线状态缓慢变化且不会进入死亡或清档状态；
- 支持手机窄屏和桌面浏览器，数据写入当前运行环境的本地存储；
- 提供网页应用清单与离线缓存，可从本机 HTTP 服务安装为 PWA。
- 提供轻量 Android WebView 安装包，可离线直接运行同一套宠物机页面。

## 快速开始

需要 Python 3。无需安装项目依赖。

在项目目录运行：

    npm run start

然后打开 http://localhost:4173。也可以直接打开 index.html 使用；直接打开时照料功能可用，但浏览器的 PWA 安装与离线缓存需要 localhost 或 HTTPS。

## 手机上运行（Android）

需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.0，以及已授权的 ADB 设备。在项目目录执行：

    powershell -ExecutionPolicy Bypass -File .\android\build.ps1
    adb install -r .\android\build\yao-pocket-pet.apk
    adb shell am start -n com.tinderbox.yaopocketpet/.MainActivity

安装包把页面资源打包在应用内，不依赖电脑上的 localhost 服务或手机网络。当前构建使用本地调试签名，用于开发和侧载安装。
