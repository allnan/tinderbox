# 使用说明

## 打开应用

需要 Python 3。进入项目目录运行 npm run start，再用手机或电脑浏览器打开 http://localhost:4173。首次打开后，静态资源会缓存到本机；之后可以在浏览器支持的离线应用入口继续打开。

也可以直接打开项目里的 index.html。这种方式可以照料阿咬，但浏览器通常不会启用 PWA 安装和离线缓存。

## 在 Android 手机上安装

需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.0，以及已授权的 ADB 设备。连接手机并打开 USB 调试后，在项目目录运行：

    powershell -ExecutionPolicy Bypass -File .\android\build.ps1
    adb install -r .\android\build\yao-pocket-pet.apk
    adb shell am start -n com.tinderbox.yaopocketpet/.MainActivity

安装包内置当前页面资源，启动后不需要电脑保持运行，也不需要网络。Android 应用与浏览器网页各自保存独立的宠物状态；卸载 Android 应用会清除该应用保存的数据。此 APK 使用开发调试签名，适合个人侧载体验，不是商店发布包。

## 照料和互动

机壳下方的三个实体键会打开不同玩法：

| 按键 | 操作 | 玩法 |
| --- | --- | --- |
| A · 投喂 | 打开食物选择 | 野地莓果免费；墨香团子消耗 2 枚墨点；清心菌菇消耗 1 枚墨点。三种食物恢复状态的组合不同。 |
| S · 互动 | 打开轻互动菜单 | 可以追叶子、躲猫猫、贴贴或听阿咬说话；“追墨点挑战”是可选的 12 秒小游戏。 |
| D · 护理 | 打开护理菜单 | 梳理毛发可免费改善洁净度；温水擦拭消耗 1 枚墨点、恢复更多洁净；也可让阿咬睡觉或叫醒它。 |

### 直接触摸 LCD

- 摸头、碰脸、挠脚或碰到阿咬生物左侧嘴角的口水边，会触发不同动作、短句和像素效果。
- 点阿咬附近的空地，它会小跑到你点的位置；待机时也会偶尔眨眼、闻闻、伸展或在草地间散步。
- 追叶子时可以再点飞过的叶子，阿咬会追上去接叶子；躲猫猫时点屏幕即可把它找出来，等待一会儿它也会自己探头回来。
- LCD 的天空会按本地时间在清晨、白天、黄昏和夜间之间变色，云朵和花会缓慢移动。

键盘 A、S、D 或数字键 1、2、3 也能打开相同菜单。

每日完成三次喂食、护理、摸摸或互动，会额外获得 3 枚墨点。追墨点挑战会消耗少量体力和饱食，分数会记入旅记；在旅记中可以查看最近的照料记录、相伴天数、亲密等级和最佳抓取成绩。

## 状态、睡眠和保存

- 饱食、心情、体力和洁净度以 0 到 100 显示。亲密度升到 20、40、60、80 时分别提升称号等级，最高 Lv.5。
- 睡眠期间每小时恢复 18 点体力，并轻微消耗饱食和洁净度；体力恢复到 100 后自动醒来，点阿咬也可以提前唤醒。
- 清醒或离线时需求会缓慢变化，离线变化最多按 48 小时计算；阿咬不会死亡或清档。
- 状态、墨点、相伴天数、小游戏成绩和最近 12 条旅记保存在当前运行环境的本地存储中。升级会从旧版存档迁移已有状态；换浏览器或清除站点数据后不会自动同步。
- 应用不连接游戏服务或云端，也不上传宠物数据。
