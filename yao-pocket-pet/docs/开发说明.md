# 开发说明

## 技术栈

- 原生 HTML、CSS 与 JavaScript，无第三方运行依赖。
- Python 3 标准库 HTTP 服务用于本地开发。
- Web App Manifest 与 Service Worker 提供支持条件满足时的安装和静态资源离线缓存。
- Android Java WebView 壳用于生成可侧载安装的离线 APK；不依赖第三方 Android 库。

## 目录与入口

| 路径 | 用途 |
| --- | --- |
| index.html | 单页界面、宠物机外壳、屏幕与阿咬像素素材入口。 |
| styles.css | 手机优先布局、复古机壳、像素屏幕、阿咬的动作反馈、场景对象和晨昏变化。 |
| app.js | 存档迁移、宠物需求、部位触摸反馈、场景移动、轻互动、照料、可选小游戏、每日目标、旅记和本地时间模拟。 |
| manifest.webmanifest | 可安装网页应用的名称、显示模式与图标。 |
| service-worker.js | 缓存静态应用文件。 |
| assets/yao-pixel.png | 原始正面阿咬素材，并继续用作应用图标。 |
| assets/yao-actions-4x4.png | 4 × 4 透明逐帧素材表：待机、行走、进食和睡眠各 4 帧。 |
| android/src/main/AndroidManifest.xml | Android 应用名称、入口和最低系统版本。 |
| android/src/main/java/com/tinderbox/yaopocketpet/MainActivity.java | 将同一套 HTML、CSS、JavaScript 装入 Android WebView。 |
| android/build.ps1 | 使用本机 Android SDK 与 JDK 17 构建并签名调试 APK。 |
| docs/资料来源与角色设定.md | 游戏与角色资料来源、项目设定边界。 |
| docs/设计核对.md | 截图对照的核对状态、证据和阻塞项。 |

页面把红色宠物机作为手机主画面，机壳内包含 LCD、状态条和照料按键。逐帧角色动作来自 `assets/yao-actions-4x4.png`；CSS 为不同照料和互动叠加动作反馈、临时道具与场景移动。

## 开发与运行

在项目目录执行：

    npm run start

开发服务器使用 Python 3，在 http://localhost:4173 提供静态文件。更改后刷新页面即可。项目不需要 npm install。

构建 Android 安装包时，在项目目录执行：

    powershell -ExecutionPolicy Bypass -File .\android\build.ps1

脚本从 `ANDROID_SDK_ROOT`、`ANDROID_HOME` 或 PATH 中的 `adb` 推导 SDK 目录，使用 Android SDK Platform 35、Build Tools 35.0.0 和 JDK 17。APK 输出到 `android/build/yao-pocket-pet.apk`；构建目录及本地调试密钥不会加入版本管理。Android 壳把 CSS、JavaScript 和逐帧 PNG 内联到本地 HTML，在 WebView 的稳定应用来源下保存状态，不请求外网。当前构建版本为 1.7（versionCode 8）。

## 验证方法

- node --check app.js：检查 JavaScript 语法。
- python -m json.tool manifest.webmanifest：检查网页应用清单格式。
- 在 http://localhost:4173 打开页面，验证食物菜单、小游戏计时和奖励、清洁、睡眠恢复、摸摸反应、旅记及刷新后存档；并观察手机窄屏布局。
- 执行 `android/build.ps1` 后检查 APK 签名；连接 Android 设备时使用 `adb install -r` 安装并启动，检查手机上的布局和照料操作。
- 离线缓存需在 localhost 或 HTTPS 下首次打开后验证；直接以 file:// 打开不会注册 Service Worker。
